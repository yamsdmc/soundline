## [Unreleased]

### Added

- End-to-end evaluation (M5): with a language model configured, `eval run` asks every question and scores the answers with deterministic generation metrics (`answer_rate`, `false_answer_rate`, `abstention_precision`, `citation_validity`, `support_rate`, `citation_recall`, `approximate_citation_rate`, `lenient_parse_rate`), each averaged over the cases that define it. Each case records latency, tokens and cost, summarized by mean, p50, p95 and total. Model calls are cached by input, so a rerun is reproducible and free (`--no-cache` to call again); `--retrieval-only` keeps the model out.
- Streaming (M4): `ask_stream` yields `RetrievalCompleted`, one `ClaimVerified` per verified claim, then `AnswerCompleted`, or `StreamError` (GEN-050, GEN-051); `ask` consumes the same stream. `soundline chat` holds a conversation in the terminal and shows the condensed search query of each follow-up.
- Conversations (M4): `sl.conversation()` keeps previous turns in memory, and `ask(question, history=...)` takes them explicitly. A follow-up is condensed into a standalone search query by the model (RET-071, prompt `condense-v1`), and falls back to the question as asked with a warning when that fails (RET-073). History reaches the model as text only, never as citable evidence (GEN-060, GEN-063), packed newest turn first within `history_budget_tokens` (GEN-062). Answers report `query` (search query, turns used and dropped) and `warnings`. The grounded prompt is now `grounded-v3`.
- Token usage and cost (M4, GEN-070): every answer carries `usage`, tokens per stage (`generation`, `generation_retry`) with cache reads and writes apart, and an estimated cost from a price table (`GenerationSettings(prices=...)`). Local models are free; a model without a price has an unknown cost, never an understated one. The CLI prints a usage line on stderr. `LanguageModel.generate` now returns a `Generation` (text and usage), and models expose a `model_id`.
- Versioned prompts (M4): the grounded prompt ships as files (`soundline/prompts/grounded-v3`), every answer records its `prompt_version`, and a template directory can replace it (`Soundline(..., prompt=PromptTemplate.from_directory(...))`, `SOUNDLINE_PROMPT`). Claims are written in the question's language whatever the evidence language (GEN-015). An approval test pins the rendered prompt.
- Local models through any OpenAI-compatible server (Ollama, vLLM, LM Studio) with `SOUNDLINE_LLM=ollama:<model>`; claims take precedence over a blank `insufficient_evidence`, which small models send instead of `null`. Thinking is off for Ollama models (`reasoning_effort=none`), and a server without structured output falls back to JSON asked in the prompt.
- Retrieval evaluation (M3): JSONL datasets labeled by quote and strictly validated, retrieval metrics (recall, hit rate, precision, nDCG at k, MRR), 95% bootstrap intervals, paired comparisons with verdicts, `soundline eval run | compare | gate`, Markdown reports for pull requests, a committed smoke dataset with a CI gate against its baseline.
- Real local stack (M2): SQLite store (FTS5 BM25 + sqlite-vec) with a pipeline fingerprint that refuses mixed indexes, atomic document replacement, idempotent re-ingestion; hybrid search fused with RRF, with per-retriever explanations and metadata filters (builder or canonical JSON); Markdown parsing with offset maps back to the original text; structure-aware chunking with section paths; file, directory and `sync` ingestion with a per-source report; local embeddings with fastembed; the `soundline` CLI (`ingest`, `sync`, `search`, `inspect manifest`, `--json`, documented exit codes). Every port has a public contract suite in `soundline.testing.contracts`.
- Walking skeleton (M1), test-driven through the Python API: `Soundline.in_memory(llm=...)`, `ingest_text`, `ask`. Answers cite verbatim quotes verified against the evidence and resolved to document spans (GEN-030, GEN-031, GEN-032), rendered with `[n]` markers (GEN-040). An empty corpus abstains without calling the model (GEN-001). Public fakes `InMemoryIndex` and `ScriptedLanguageModel` in `soundline.testing`.
- Specification (`docs/spec`) and architecture decision records (`docs/adr`).
- Repository foundations (M0): packaging with uv and hatchling, ruff, pyright strict, pytest with Hypothesis profiles and network disabled, import-linter layer contracts, domain purity guard (ARC-001), spec traceability script, CI on Linux, macOS and Windows, SQLite extension probe (ARC-014 spike).
